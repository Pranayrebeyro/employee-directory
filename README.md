# Employee Directory - Ajackus Frontend Assignment

## Overview

A responsive Employee Directory built with HTML, CSS, JavaScript, and Freemarker templates.

## Features

- Employee list with edit/delete
- Add/Edit employee form
- Search, filter, sort (extend as needed)
- Pagination
- Responsive design

## Setup

1. Clone or download this repo.
2. Open in VS Code.
3. Install Live Server extension.
4. Right-click index.html -> Open with Live Server.

## Folder Structure

- data/ - mock JSON employee data
- templates/ - Freemarker templates
- public/css/ - CSS styles
- public/js/ - JavaScript logic
