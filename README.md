# Employee Directory

A clean and responsive employee directory built with React and Vite.

The application allows users to view, search, filter, sort, add, edit, and delete employee records through a simple and practical interface.

## Live Demo

https://employee-directory-virid-three.vercel.app/

## GitHub Repository

https://github.com/Pranayrebeyro/employee-directory

## Features

- View all employees
- Search employees by name, email, department, or role
- Filter employees by department
- Filter employees by role
- Sort employees by name, department, or role
- Choose the number of employees displayed per page
- Pagination
- Add new employees
- Edit existing employees
- Delete employees
- Form validation
- Data persistence using browser localStorage
- Responsive design for desktop, tablet, and mobile
- Clean and simple user interface
